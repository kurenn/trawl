# trawl-cli — 2026-10-05

- **Tokio runtime drop blocks on `spawn_blocking`** — `tokio::time::timeout(spawn_blocking(..))`
  abandons the future, not the thread; dropping the runtime then waits for that thread forever
  (a `stat` on a wedged CIFS mount). In a CLI, call `rt.shutdown_background()` before exit.
- **Probing a file lock takes it** — `is_running` via `try_lock` holds the lock for a moment, so a
  concurrent real claim can see `WouldBlock`. Claims retry a few times (5×20ms); probes don't.
- **Race tests need synchronization, not tight loops** — a looping prober made the retry test
  flaky (11/100 under load). Hold the lock in a helper thread, signal over a channel, then claim;
  verify the test fails with the retry disabled.
- **macOS ignores `XDG_DATA_HOME`** — `dirs::data_dir()` is `~/Library/Application Support`
  there, so XDG-redirected integration tests would hit real user data. Gate them to Linux.
- **tauri-build copies the rclone sidecar to `target/<profile>/`** — anything resolving rclone
  "next to the exe" picks the real one in tests. Hard-link the test binary next to a fake
  (copying to `/tmp` across filesystems flaked with `ExecutableFileBusy`).
- **Leaving the tauri crate loses feature unification** — tokio's `fs` feature came in via tauri;
  `trawl-core` must declare it itself. Same for `serde_json`, which `generate_context!` needs
  in `src-tauri` even when unused directly.
- **Shared settings flags cut both ways** — the app's "Auto · paused" toggle is the same
  `auto_sync_enabled` the systemd timer honours; docs must not suggest pausing one to use the other.
- **systemd unit values** — quote `Environment="PATH=…"`, double `%`, and give every unit that
  shells out to rclone (including the `sync-due` oneshot) the install-time PATH.
